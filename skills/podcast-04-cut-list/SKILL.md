# Step 4: edit list
1. `candidates.py` → `work/candidates.json` (rules in playbook §3, thresholds `candidates.*`, word lists `text.*`).
2. `label_store.py seed` (rule labels; auto-approve only `labels.auto_approve_types`; existing labels are reused, keyed by hash(candidate+context)).
3. For each non-auto candidate read `context`, then `label_store.py set <key> <cut|duck|mute|keep|review> [--approve] --by agent --note …`. Anything touching meaning, jokes, or a pause before a laugh stays `review` for the user (`review_export.py` → Audacity → `review_import.py`). Overlapping pure laughter is the exception in `candidates.overlap_laughter`: mute only the losing speaker's laughter interval, and only when the winner is unambiguous (three-speaker rule) or configured (two-speaker `role_map`). Ambiguous cases stay review.
4. `label_store.py build` writes `work/edits.json`; it fails on unlabeled candidates.
Types: `long_pause` (union-VAD gaps > 1.2 s within / 1.5 s between speakers → 0.7 s, review if laugh within 2 s), `filler`, `backchannel` (-20 dB duck on own track), `overlap_yield` (mute only the yielder), `overlap_restart` (X's short phrase ≤ `candidates.overlap_restart.max_s` overlapped by another speaker starting within `overlap_onset_s`, restarted within `restart_window_s` sharing ≥1 reading-normalized content word not in `light_words` → AUTO mute X's aborted phrase on X's track only; timeline and the other speaker untouched; auto-approved, replaces any overlap_yield on that span so keep_overlap_yield cannot auto-keep it; the following silence is left to `long_pause`; **interjection case**: instead of the onset match, X's phrase may start inside another speaker's ongoing substantive line that began ≥ `interject_lead_s` earlier — skipped when the phrase matches `interject_end_re` (か / ? / 。！), e.g. 「2022年か」「前半?後半?」「すごいね。」), `overlap_abandon` (X's phrase ≤ `overlap_abandon.max_s`, not aizuchi/filler/laugh and not matching `sentence_end_re`, inside Y's ongoing substantive line; Y continues ≥ `continue_after_s` past X's end and X is silent `silent_after_s` → AUTO mute X's track only), `mutual_yield` (both onsets within `overlap_onset_s`, both phrases ≤ `yield_max_s`, one says a `mutual_yield.markers` word (どうぞ/お先に) within `yield_marker_window_s`, the other restarts within `restart_window_s` → AUTO timeline cut from the first onset to `gap_s` (0.4 s) before the restart; review if a third speaker talks inside or head/tail/laugh; overrides keep_overlap_yield and drops the smaller edits inside), `false_start`, `overlap_laughter` (pure overlapping laughs only: three at once keep the unique speaker who is neither interviewee nor primary host and mute the other laughter intervals on their own tracks; two laughs stay review unless `two_speaker: role_map` names a winner; never a timeline cut; speech, questions, backchannels, and mixed speech/laughter are not muted), `crosstalk`, `mistake`. Never timeline-cut meaning, jokes, or laughs, or head/tail content.
